# หมูกระทะจำนวนนับที่หารด้วย 3 ลงตัว

![Cover](assets/cover.jpg)

เกมเว็บแนวคณิตศาสตร์/ปฏิสัมพันธ์ ให้ผู้เล่นเลือกชิ้นหมูที่มีเลขหารด้วย 3 ลงตัวไปวางบนจานภายในเวลา 120 วินาที

## ฟีเจอร์

- หน้าเมนูพร้อมวิดีโอพื้นหลัง
- โหมดเล่นปกติ: ลากหมูด้วยเมาส์หรือสัมผัส
- โหมด AR: ใช้กล้องตรวจจับมือเพื่อคีบหมู
- เพลงประกอบและเสียงเอฟเฟกต์ตอนเล่น
- รองรับมือถือ

## โครงสร้างไฟล์

- `index.html` — หน้าเกมหลักทั้งหมด
- `assets/` — ไฟล์สื่อของเกม
  - `cover.jpg` — ภาพปก
  - `cover.mp4` — วิดีโอหน้าเมนู
  - `table.svg` — พื้นหลังหน้าเล่นเกม
  - `mookata-tao.svg` — เตาหมูกระทะ
  - `plain.svg` — จาน
  - `pork.svg` — ชิ้นหมู

## วิธีใช้งาน

1. เปิด `index.html` ในเบราว์เซอร์
2. เลือกโหมดที่ต้องการ
3. ในโหมด AR อนุญาตการเข้าถึงกล้องเมื่อระบบร้องขอ

## หมายเหตุ

- โหมด AR ใช้ `@mediapipe/tasks-vision` จาก CDN
- วิดีโอหน้าเมนูอาจต้องแตะหน้าจอครั้งแรกเพื่อให้เสียงเล่นได้บนมือถือ
