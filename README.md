# หมูกระทะจำนวนนับที่หารด้วย 3 ลงตัว

![Cover](assets/cover.jpg)

เกมเว็บแนวคณิตศาสตร์ + ปฏิสัมพันธ์ (single-page) — ผู้เล่นเลือกชิ้นหมูที่มีเลขหารด้วย 3 ลงตัวแล้วคีบใส่จานให้ทันภายใน 120 วินาที

## สิ่งที่เปลี่ยน / ฟีเจอร์สำคัญ

- เมนูหน้าแรกมีวิดีโอพื้นหลังและปุ่มเมนูสีสันชัดเจน (ปรับขนาดบนมือถือ)
- โหมดปกติ: ลาก/คลิกเพื่อหยิบหมู (รองรับเมาส์และสัมผัส)
- โหมด AR: ใช้กล้องและ MediaPipe HandLandmarker ตรวจจับการคีบ
- เสียง: ใช้ Tone.js สำหรับ BGM/beeps และไฟล์ `assets/correct.mp3` / `assets/wrong.mp3` สำหรับฟีดแบ็คผลการเลือก
- นับถอยหลัง 5→1 แสดงบน canvas (ฉากยังมองเห็นได้ระหว่างนับถอยหลัง)
- ปรับ canvas ให้คมบนหน้าจอความละเอียดสูง (devicePixelRatio)

## โครงสร้างไฟล์

- `index.html` — เกมทั้งหมด (JS, CSS, canvas, UI)
- `assets/` — สื่อของเกม (ตัวอย่าง)
  - `cover.mp4`, `cover.jpg` — หน้าเมนู
  - `table.svg`, `mookata-tao.svg`, `plain.svg`, `pork.svg` — ภาพประกอบเกม
  - `correct.mp3`, `wrong.mp3` — เสียงผลถูก/ผิด

## วิธีรัน (แบบง่าย)

1. เปิดเทอร์มินัลในโฟลเดอร์โปรเจค
2. รันเว็บเซิร์ฟเวอร์แบบง่าย (เช่น Python 3):

```bash
python3 -m http.server 8000
```

3. เปิดเบราว์เซอร์ที่ `http://localhost:8000` แล้วโหลด `index.html`

## หมายเหตุสำคัญ

- เบราว์เซอร์จำกัดการเล่นเสียงอัตโนมัติบนมือถือ/บางเงื่อนไข — เกมจะเริ่ม Tone.js / WebAudio หลังจากผู้ใช้กดปุ่มเมนู (gesture) เพื่อให้เสียง BGM/เอฟเฟกต์ทำงานได้อย่างถูกต้อง
- หากเสียงไม่ดังบนมือถือ ให้แตะปุ่มเมนูแล้วรอสักครู่แล้วเริ่มเกมอีกครั้ง
- โหมด AR ต้องอนุญาตการเข้าถึงกล้อง; ตรวจสอบสิทธิ์กล้องในเบราว์เซอร์
- หากภาพบน canvas เบลอ ให้แน่ใจว่าใช้หน้าจอความละเอียดสูง (devicePixelRatio) และเรียก `resizeCanvas()` เมื่อขนาด viewport เปลี่ยน

## แก้ไขที่แนะนำต่อ

- ปรับเฉดสีปุ่มหรือขนาดบนมือถือเพิ่มเติมตามดีไซน์ทีม
- เพิ่มการทดสอบบนอุปกรณ์จริง (iOS Safari, Android Chrome) เพื่อยืนยันพฤติกรรมกล้องและเสียง
