จงสร้างเกม AR เปิดกล้อง วิชา คณิตศาสตร์ เรื่อง จำนวนนับที่หารด้วย 3 ลงตัว โดยใช้ HTML, CSS (Tailwind) และ JavaScript ในไฟล์เดียว (Single File) และไม่ใช้ Backend 

รายละเอียดของเกม
ชื่อเกม: "หมูกระทะจำนวนนับที่หารด้วย3ลงตัว"
จำนวนหน้า: 2 หน้า แบ่งเป็น หน้าแรกของเกม ที่จะมีปุ่มเริ่มเล่นเกมทั้งแบบธรรมดา และแบบรองรับ AR
หน้าแรก(index): พื้นหลังเป็นวิดีโอ และมีปุ่ม 3 ปุ่ม คือ
    1. ปุ่มวงกลมรี "เล่นโหมดปกติ" ตำแหน่งอยู่ตรงกลาง
    2. ปุ่มวงกลมรี "เล่นโหมด AR" ตำแหน่งอยู่ตรงกลาง วางข้างๆกับ "ปุ่มเล่นโหมดปกติ"
    3. ปุ่มกลม "?" ตำแหน่งอยู่ขวาบนของหน้าจอ

หน้าที่สอง(in-game):
mechanic ของเกม: เมื่อเข้าสู่หน้าเล่นเกม ตัวเกมจะทำการสร้างหมูจำนวน 4 ชิ้น ที่มีตัวเลขที่หารด้วย 3 ลงตัว 1 ชิ้น และอีก 3 ชิ้น หารด้วย 3 ไม่ลงตัว วางรวมกันแบบไม่ทับกันและให้อยู่ในวงกระทะ
หากตอบถูกหรือผิด จะทำการรีเซ็ตหมูทั้ง 4 ชิ้น

ระยะเวลาของเกม: 120 วินาที

โหมดธรรมดา
- ให้ทำการลากหมูใส่ลงจานเพืื่อตรวจคำตอบ
โหมด AR
- ตัวเกมจะทำการตรวจจับมือ เมื่อตรวจพบมือให้แสดงภาพตะเกียบ
เมื่อตรวจพบกการจีบมือ จะทำการหยิบหมู หากมีการปล่อยมือลงในตรงตำแหน่งของจานเพื่อตรวจคำตอบ

การตรวจคำตอบ: 
- หากตอบถูกจะมีเสียงสดใสน่ารักพูดคำว่า "อิ่มอร่อยเก่งมาก" และมีเสียงเอฟเฟ็กถูกและเอฟเฟ็กถูกแบบเวอร์ๆ 
- หากตอบผิดจะมีเสียงสดใสน่ารักว่า "หิวจังลองใหม่จ้ะ" และมีเสียงเอฟเฟกต์ผิดและเอฟเฟ็กผิดแบบเวอร์ๆ 

โดยการใช้รูปแบบการติดตามมือ AR Hand traking โดยเห็นตำแหน่งมือที่จีบจะหยิบหมูได้อย่างชัดเจนแม่นยำ

- ปุ่มกดมีเอฟเฟกต์ยุบตัวเมื่อกดวาดฉากด้วย Canvas ล้วนๆ
